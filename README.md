# META4PRO — основа редизайна v3

Отдельная адаптивная основа редизайна, не заменяющая действующий сайт.

Онлайн-версия: https://trip-prog.github.io/meta4pro-redesign/

## Запуск

Самый простой способ в Windows: дважды нажмите `ОТКРЫТЬ_САЙТ.cmd`. При первом запуске зависимости установятся автоматически, затем откроется интерактивный прототип в браузере. Чтобы остановить локальный сайт, закройте появившееся окно `META4PRO Preview`.

Или вручную:

```powershell
npm.cmd install
npm.cmd run dev -- --port 4174
```

Локальный адрес: `http://127.0.0.1:4174/meta4pro-redesign/`.

## Что сделано

- mobile-first интерфейс от 360 px и полноценная десктопная композиция;
- живое «матч-лобби» с редакционной типографикой и реальными фото клуба;
- ПК собирается из девяти отдельных прозрачных фотореалистичных слоёв и завершается цельной фотографией;
- выбор GENERAL / ARENA / BOOTCAMP / SIGMA с ценой и характеристиками;
- Liquid Ether только на подходящих десктопах, Electric Border на финале сборки, Circular Gallery на широких экранах;
- локальные шрифты Unbounded и Onest, без зависимости от Google Fonts;
- доступные контакты: телефон, Telegram и переход к актуальным тарифам.
